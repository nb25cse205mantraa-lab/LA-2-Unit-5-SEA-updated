## 1. Introduction

Mobile and web applications are software applications developed to provide services through digital platforms.

A web application runs through a web browser, whereas a mobile application is installed on smartphones.

A Progressive Web Application (PWA) combines features of both mobile and web applications. It can be accessed through a browser and installed on a mobile device.

## 2. Problem Analysis

A college canteen usually receives food orders directly from students at the counter.

This traditional method creates several problems:

- Students have to wait in long queues.
- Ordering food during break time becomes difficult.
- Students cannot check food availability in advance.
- Manual order management may cause mistakes.
- Payment and order tracking take additional time.

To overcome these problems, the college needs an online canteen food-ordering system.

## 3. Comparison of Mobile, Web and PWA Applications

**1. Mobile Application**

- Installed directly on smartphones.
- Provides push notifications.
- Requires installation and regular updates.

**2. Web Application**

- Accessed through a web browser.
- Does not require installation.
- Can be accessed from different devices.

**3. Progressive Web Application (PWA)**

- Works through a web browser.
- Can be installed on smartphones.
- Supports push notifications on supported devices.
- Provides a mobile-app-like experience.

## 4. Selection of Suitable Application

A Progressive Web Application (PWA) is the most suitable choice for the college canteen system.

Students can access the application using a browser without downloading it from an app store.

They can also install it on their smartphones for easier access.

A PWA reduces development and maintenance costs while providing important features such as notifications and a responsive interface.

Therefore, a PWA is a suitable solution for the proposed online canteen food-ordering system.

## 5. Major Functionalities

**1. Student Registration and Login**

Students can create accounts and log in securely to access the canteen application.

**2. Digital Menu**

Students can view available food items, prices and descriptions.

**3. Online Food Ordering**

Students can select food items, add them to the cart and place orders.

**4. Online Payment**

The system supports digital payment methods such as UPI and other available payment gateways.

**5. Order Tracking and Notifications**

Students can track their order status and receive notifications when their food is ready.

## 6. Development Challenges

**1. Payment Security**

The application must protect students' payment information and ensure secure transactions.

**2. Network Connectivity**

A stable internet connection is required to place orders and receive real-time updates.

**3. Order Management**

The system must handle multiple orders simultaneously and avoid incorrect or duplicate orders.

## 8. Conclusion

The online canteen food-ordering system provides an effective solution to the problems of traditional food ordering.

A Progressive Web Application is suitable because it provides easy accessibility, installation support and a mobile-friendly experience.

It reduces waiting time, improves order management and makes digital payments easier.

Therefore, implementing a PWA-based canteen system will improve the overall food-ordering experience for students and canteen staff.
